# 珠光3F空间演示

按2026-11-04 R02图册呈现315、303、301区域, 包含20人会议室、服装展示厅、仓库和两间试衣间. 室内净高3.5m. 315/303之间采用不可看穿的磨砂玻璃, 主入口为自动对开移门, 其余五处门为平开门.

手机点右上角“场景设置”操作屋顶、墙面和门. 单指旋转或环顾, 双指缩放, 室内点击箭头移动. 横屏展开设置后为左右分栏. 电脑可使用鼠标和WASD操作.

所有运行依赖均存放于本仓库vendor目录, 无外部CDN资源. GitHub Pages从main分支根目录发布, .nojekyll保留静态文件原样部署.

本地启动: `python3 -m http.server 8766`

检查: `node --check app.js && node validate.mjs`

网页是实时方案演示, 家具材质、灯光和天线圆为示意. 门窗竖向尺寸使用已确认方案值, 不作为现场实测尺寸.
